Projeto desenvolvido em HTML para armazenar e acessar meus sites favoritos de forma simples e organizada.

## Sites escolhidos
- Chess.com
- Claude AI
- YouTube
- Spotify
- GitHub

## Tecnologias utilizadas

## Recursos do projeto
- Imagens dos sites
- Links clicáveis
- Organização visual com títulos e separadores
- Abertura dos links em nova aba
